# تحديث تطبيقَي الإدارة والكابتن من الداخل — 1.4.0

يفحص Android الإصدار عند فتح التطبيق والعودة إليه، قبل تسجيل الدخول ومن دون تعطيل العمل عند انقطاع الشبكة. عند وجود نسخة أحدث ومتوافقة يظهر تنبيه بالإصدار والحجم والملاحظات وخيار «تحديث الآن» أو «لاحقًا». بعد التأجيل لا يتكرر التنبيه في الجلسة نفسها.

التنزيل داخل التطبيق مع نسبة مئوية وإلغاء وإعادة محاولة. الملف يُحفظ في مجلد خاص مؤقت؛ لا يحتاج إذن الوصول إلى ملفات المستخدم. لا يُفتح مثبت Android إلا بعد مطابقة حجم الملف وSHA-256 ومعرّف الحزمة ورقم الإصدار وشهادة توقيع التطبيق المثبّت. يُرفض ملف التطبيق الآخر والملف التالف والتوقيع المختلف. عند طلب Android إذن تثبيت التطبيقات غير المعروفة، يعود التطبيق إلى التثبيت بعد منح الإذن، ويعيد التحقق من الملف.

التثبيت يحتاج موافقة المستخدم في نافذة Android. يحتفظ التحديث بالحساب وبيانات التطبيق. الملفات الجاهزة تبقى متاحة بعد إعادة فتح التطبيق، ويُحذف ملف النسخة القديمة عند نجاح الترقية. لا تثبيت صامت ولا إذن تخزين شامل.

## أول انتقال من النسخ السابقة

النسخ 1.2/1.3 لا تحتوي منطق التنزيل والتثبيت الأصلي. الواجهة المنشورة تعرض لها تنبيهًا ورابط تنزيل النسخة الجديدة. بعد تثبيت 1.4.0 مرة واحدة تصبح التحديثات التالية داخل التطبيق بالكامل. المتصفحات العادية لا تعرض تنبيه تحديث Android. المضيف الجديد يعلن قدرته لتجنّب ظهور تنبيهين.

## نشر نسخة جديدة

1. ارفع `versionCode` و`versionName` وابنِ APK للتطبيقين من commit معتمد على `main`، ثم وقّعهما **بالشهادة الأصلية** وتحقق من الحزم والإصدارات والتوقيع.
2. شغّل `npm run prepare:android-release -- --apks /absolute/path/to/signed-apks --source FULL_COMMIT_SHA --notes-file /absolute/path/to/notes.txt`. ينتج `artifacts/android-release/latest.json` و`release-notes.md`.
3. انشر GitHub Release باسم `android-vVERSION` على commit المصدر نفسه، وأرفق `Delivery-Admin-VERSION.apk` و`Delivery-Captain-VERSION.apk`. تحقق من بصمات الملفات المنشورة بعد تنزيلها.
4. **بعد** إتاحة الملفين للعامة، حدّث `latest.json` على فرع `android-releases` بالمحتوى المتولد. هذا الفرع مخصص لبيانات الإصدار، ولا يغيّر كود `main`.
5. نزّل بيان الإصدار الحي وتحقق من رقمَي الإصدار والحجم والبصمات ومطابقة sourceCommit. الإصدار لا يصبح متاحًا للتحديث داخل التطبيقات قبل هذه الخطوة.

عنوان البيان الثابت: `https://raw.githubusercontent.com/louay1992/mahmoud/android-releases/latest.json`. روابط APK محصورة بإصدارات المستودع نفسه، مع السماح بإعادة توجيه HTTPS إلى مخازن GitHub الرسمية فقط. لا تدخل مفاتيح التوقيع أو حساب الخدمة إلى البيان أو APK.

## الاختبارات

اختبارات Android تغطي المقارنة والتوافق، رفض ملف/حزمة/توقيع غير مناسب، تلف التنزيل وانقطاعه وإلغاؤه، أذونات URI ومجلد المشاركة، وظهور التنبيه قبل تسجيل الدخول وتأجيله. اختبارات المتصفح تغطي تنبيه النسخ السابقة، رابط التطبيق الصحيح، التركيز وعرض الهاتف، وعدم تكرار تنبيه المضيف الجديد. اختبار المستخدم الأخير: تحديث جهاز فعلي من نسخة سابقة ثم فتحه دون إزالة التطبيق، والتحقق من بقاء الجلسة ووصول إشعارات FCM.
